# Galmuri11

Unmodified Galmuri11 regular and bold WOFF2 files from `galmuri@2.40.3`.

- Source: https://github.com/quiple/galmuri
- Copyright: Lee Minseo
- License: SIL Open Font License 1.1; see `LICENSE.txt`.

The build embeds the fonts and their license in the standalone UI. Binary FontFace sources avoid network requests and work with the MCP widget's restrictive font policy. The native Claude Code text uses the host's font; its progress SVG and borders use the same monochrome block treatment.
