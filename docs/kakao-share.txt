[CheckYourProcess] 같이 만들어 보실래요? 🙂

울트라코드로 서브에이전트에게 일을 맡겨 두면 어디까지 진행됐는지 감이 안 와서 만들었어요. AI와 합의한 작업 목록, 완료 수, 실행·대기 상태를 작은 진행 바로 보여 줍니다.

지금은 Windows 한 대에서 쓰는 beta.5예요. 설치부터 첫 추적, 상태 갱신, 재시작 후 복원까지 매끄럽게 다듬는 중입니다. 여러 PC 사이에 진행률을 동기화하는 서비스는 아니에요.

평소 쓰시는 ChatGPT / Claude Desktop / Claude Code / Codex CLI 중 하나로 함께 개선해 보실 분을 찾고 있어요. 설치해 보기, 막힌 곳 알려 주기, 문서 고치기처럼 작은 참여도 반가워요. 관심 플랫폼과 사용 환경을 GitHub 이슈에 남겨 주세요.

GitHub · 소개·설치·참여 안내
https://github.com/SWJoong/CheckYourProcess
