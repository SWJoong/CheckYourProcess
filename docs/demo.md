# 시연 영상과 촬영 기록 — 0.1.0-beta.5

2026-11-13에 터미널과 Desktop Code 탭의 **배속 요약본 2개 제작을 완료**했습니다. 공유할 파일은 [영상 설명](videos/README.md)에 정리했고, README에도 두 파일을 각각 연결했습니다. 합친 1분 영상은 사용하지 않습니다.

터미널 원본은 편집 없는 연속 촬영이지만, 공유용 요약본에는 구간 선택·배속·자막·강조 표시가 있습니다. 키·마우스 입력은 자동화 도구로 주입했으며 모델 응답과 도구 호출은 실제 호스트에서 실행됐습니다. Desktop 영상은 사용자가 촬영한 **Code 탭**의 앞 4분 25초를 요약하고 사이드바·계정 메뉴를 가렸습니다. `.mcpb`를 사용하는 일반 Chat 탭은 촬영하지 않았습니다.

2026-11-13 공개 준비 검사에서 두 요약본 전체의 디코딩, 코덱·길이·음성 트랙 유무, 2초 간격의 총 51개 프레임을 확인했습니다. 사람이 영상을 처음부터 끝까지 재생하며 개인정보·알림·짧은 화면 오류를 확인하는 최종 검수는 별도입니다. 원본과 편집 도구는 `.local/demo/`에 유지하고 공개 파일에는 포함하지 않습니다.

아래는 재촬영할 때 참고할 **원본 촬영용 큐시트와 리허설 기록**입니다. 설치부터 시작하는 새 사용자 시연은 여전히 별도 확인이 필요합니다.

## 촬영 전 준비

- Windows·Node·대상 앱·CheckYourProcess의 실제 버전을 기록합니다.
- 공개해도 되는 별도 테스트 작업과 로컬 데이터 디렉터리를 사용합니다. 개인 대화, 토큰, 인증 URL, 터널 키가 녹화 화면에 나타나지 않도록 창을 준비합니다.
- 처음에는 검증 기반이 있는 Claude Code 한 플랫폼을 대상으로 합니다. 다른 플랫폼은 실제 검증 후 각각 촬영합니다.
- 설치가 이미 끝난 상태에서 시작한다면 그 사실과 설치 안내 링크를 시작 화면에 밝힙니다. 설치 장면을 담는 경우 [설치 안내](installation.md)를 그대로 따릅니다.

## 한 번에 보여 줄 흐름

| 순서 | 보여 줄 내용 | 확인할 결과 |
| --- | --- | --- |
| 1 | 저장소·버전·지원 범위, 소스 빌드와 대상 앱 설치 | 실행한 명령과 앱이 분명함 |
| 2 | 새 대화에서 추적 시작, `시연` 프로젝트에 문서 작성·검증·리뷰 등록 | 0/3, 바 또는 카드 표시 |
| 3 | 짧은 예제 문서를 실제로 작성하고 첫 작업 완료 보고 | 1/3, 33% |
| 4 | 상세 보기, 한국어·English 전환 | 목록·라벨 갱신, 사용자 작업명 유지 |
| 5 | 두 번째 세션에서 기존 프로젝트 ID 선택, 기존 작업 ID 연결 | 프로젝트 총 작업 수가 3으로 유지 |
| 6 | 두 번째 작업을 실제로 검증하고 완료 보고 | 두 세션의 프로젝트 보기에 2/3, 66% (소수점 버림) |
| 7 | 추적 종료와 재시작·명시적 재개 | 남은 작업은 미완료, 기존 작업·언어 설정 보존 |

Claude Code에서는 입력창 위 바와 **상세**를 사용합니다. 대화 안 카드를 호출하지 않습니다. CLI나 브라우저 미리보기만 촬영했다면 영상 제목·설명에도 그 범위를 표시합니다.

## 리허설로 확인한 것

촬영 전에 실제 Claude Code 2.1.323과 빌드한 0.1.0-beta.5 설치본으로 2~7단계를 한 번 돌렸습니다. 영상이 아닌 리허설이며, 입력은 한 턴씩 실행하는 방식(`claude -p`)이었고 입력창 위 바는 대화형 화면에서 따로 확인했습니다. 별도 데이터 폴더와 포트를 썼습니다.

| 순서 | 확인한 결과 |
| --- | --- |
| 2 | `시연` 프로젝트와 작업 3개, 0/3 · 0% |
| 3 | 예제 문서를 쓴 뒤 첫 작업만 완료, 1/3 · 33%. 바에 33%, `1/3 완료`, `상세` 버튼 표시 |
| 4 | 대화로 English를 저장하거나(전체 화면 렌더러에서는 `English`·`한국어` 버튼 클릭으로도) 바 라벨이 `Interrupted`·`2/3 complete`·`Details`로 바뀌고 프로젝트·작업 이름은 그대로 |
| 5 | 두 번째 세션이 기존 프로젝트·작업 ID에 연결, 프로젝트 총 작업 수 3 유지 |
| 6 | 두 세션 모두 2/3 · 66%, 세 번째 작업은 대기 |
| 7 | 추적 종료 뒤 서비스를 껐다 켜고 다른 대화 ID의 새 세션에서 명시적으로 재개, 2/3 · 66%·미완료 작업·언어·작업명 보존 |

이후 입력창 위 바의 **상세 펼치기·한국어/English 전환·접기 버튼을 마우스로 누르는 동작**과 두 세션을 위아래로 동시에 띄운 화면(한쪽 변경이 다른 쪽 바에 곧바로 반영)도 확인했습니다. 단, 버튼 클릭은 **Claude Code 전체 화면 렌더러에서만** 동작했습니다(아래 "촬영 때 주의할 점"). 프로젝트 연결 버튼과 세션별/프로젝트 범위 버튼은 아직 눌러 보지 못했습니다.

## 촬영 때 주의할 점

- **바의 버튼을 마우스로 누르려면 전체 화면 렌더러가 필요합니다.** 기본(클래식) 렌더러에서는 `상세`를 눌러도 반응이 없었습니다. `/tui`가 `Current renderer: default`라고 답하는 상태였습니다. 셸에서 `CLAUDE_CODE_NO_FLICKER=1`로 Claude Code를 열면(또는 `/tui fullscreen`, 이쪽은 설정을 바꿉니다) 화면이 전체 화면으로 바뀌고 `상세` → `English` → `한국어` → `Compact`가 모두 눌렸습니다. 영상 설명에 이 모드를 밝히세요.
- **데이터 폴더와 포트를 분리합니다.** 두 세션을 같은 셸 설정(`CYP_DATA_DIR`, `CYP_PORT`)으로 열어야 같은 서비스를 씁니다. 훅과 바, MCP 서버가 모두 이 값을 읽으므로 기본 데이터 폴더의 기존 프로젝트와 세션이 섞이지 않습니다.
- **서비스를 미리 시작합니다.** 서비스는 첫 도구 호출 때 처음 뜹니다. 빈 데이터 폴더에서 바로 녹화를 시작하면 첫 화면 바가 `추적 시작을 요청하세요`와 함께 `연결 끊김`으로 보입니다. 빌드한 저장소나 설치된 플러그인의 `dist/cli.js`로 `node dist/cli.js start`를 먼저 실행하고 시작하세요.
- **저장소 밖의 빈 작업 폴더를 씁니다.** 저장소 안에서 열면 저장소의 프로젝트 설정과 `CLAUDE.md`가 섞입니다.
- **다른 플러그인의 훅과 스킬이 화면에 섞일 수 있습니다.** 시작 훅이 이전 세션 요약을 넣고 모델이 답변에서 언급한 사례가 있었습니다. 그 실행에서만 끄려면 설정 파일을 만들어 `claude --settings <파일>`로 엽니다. CheckYourProcess 플러그인은 켜 둡니다.

  ```json
  { "enabledPlugins": { "<촬영과 무관한 플러그인>@<마켓플레이스>": false } }
  ```

- **권한 확인 창을 줄이려면** `--permission-mode acceptEdits --allowedTools "mcp__plugin_checkyourprocess_checkyourprocess"`를 함께 씁니다. 리허설에서 권한 거부 없이 동작했습니다. 확인 창도 실제 사용 모습이라고 보면 쓰지 않아도 됩니다.
- **계획(할 일 목록) 도구가 작업 수를 바꿀 수 있습니다.** `TodoWrite`와 `update_plan`의 목록은 세션 작업으로 자동 반영됩니다. 리허설한 터미널 Claude Code 2.1.323에는 `TodoWrite`가 도구 목록에 없어 재현하지 못했습니다. `update_plan`을 쓰는 표면은 총 작업 수가 3에서 달라질 수 있으니 촬영하지 않고, 입력에 "할 일 목록 도구는 쓰지 마세요"를 넣습니다.
- **상태 표시는 이렇게 읽습니다.**
  - 서비스가 꺼진 동안 새로 연 대화의 바는 진행률 없이 `연결 끊김`이고 언어도 기본값(한국어)으로 돌아갑니다. 서비스를 켜고 재개하면 복원됩니다. 영상에서 이유를 말로 설명하세요.
  - `추적 종료` 없이 닫힌 대화는 `중단됨`(`Interrupted`)으로 기록되며, 재개한 대화도 첫 프롬프트 전까지 그렇게 보일 수 있습니다. 설계된 동작입니다. 한 턴이 끝난 대화형 화면은 `입력 대기`입니다.
- **Claude Code가 촬영 직전에 자동 업데이트될 수 있습니다.** 리허설 도중 2.1.322가 2.1.323으로 바뀌었습니다. 버전은 촬영 직전에 `claude --version`으로 다시 확인해 기록하고, 시작 화면의 공지와 업데이트 안내가 영상에 그대로 나올 수 있음을 감안하세요.

## Claude에게 전달할 요청

> CheckYourProcess 0.1.0-beta.5를 Windows의 실제 Claude Code에서 편집 없이 연속 시연해 주세요. docs/installation.md와 docs/demo.md를 기준으로 설치 또는 사전 설치 상태를 밝히고, 추적 시작 → 세 작업 등록 → 실제 작업 후 33% → 상세·언어 전환 → 두 번째 세션의 기존 작업 연결 → 66% → 추적 종료·재시작·명시적 재개를 보여 주세요. 완료하지 않은 작업은 완료 처리하지 마세요. 할 일 목록 도구는 쓰지 마세요. 개인 데이터·인증 URL·토큰을 화면에 노출하지 마세요. 실패하면 그 지점과 오류를 그대로 기록하고 성공으로 설명하지 마세요. 결과로 원본 영상 경로, 실제 환경·버전, 확인한 항목, 남은 문제를 남겨 주세요.

재촬영할 때도 실패한 지점을 잘라 성공으로 보이게 만들지 않습니다. 문제가 있으면 재현 내용을 이슈로 남기고, 수정 후 처음부터 다시 촬영합니다. 녹화 도구 조작과 원본 영상 생성은 Claude 촬영 작업에서 진행합니다.
