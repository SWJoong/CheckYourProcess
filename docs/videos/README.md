## 터미널 영상

추적 시작 → 작업 3개 등록 → 첫 작업 완료(33%) → 상세·한국어/English 전환 → 두 번째 세션이 기존 프로젝트·작업 ID에 연결 → 두 번째 작업 완료(두 창 모두 66%) → 추적 종료·서비스 재시작·명시적 재개를 보여 줍니다.

**키·마우스 입력은 자동화 도구로 주입했습니다.** 모델 응답과 도구 호출은 실제 Claude Code에서 실행됐습니다. 원본은 연속 촬영이며, 공개하는 파일은 구간 선택·배속·자막·강조 표시가 있는 요약본입니다. 프로젝트 연결 버튼과 세션별/프로젝트 범위 버튼은 이 영상에서 누르지 않았습니다.

## Desktop Code 탭 영상

새 Code 세션에 사용자가 작업을 지시하고, Claude가 만든 계획의 작업 5개를 등록해 진행 바를 갱신한 뒤 5/5·100%와 추적 종료까지 보여 줍니다. 터미널 큐시트와는 다른 작업입니다.

사용자가 촬영한 원본의 앞 4분 25초를 요약했습니다. 사이드바를 잘라 냈고, 새 세션 화면의 계정 메뉴를 검은 상자로 가렸습니다. 상세·언어 버튼 조작은 포함하지 않습니다. **Claude Desktop 일반 Chat 탭의 `.mcpb` 카드는 시연하지 않았습니다.**

## 확인 범위와 공개 전 검수

2026-11-13에 두 요약본 전체를 FFmpeg로 디코딩해 오류가 없는지 확인하고, 메타데이터와 2초 간격의 51개 프레임을 검사했습니다. 확인한 프레임에서는 계정 메뉴 가림, 진행률 변화, 자동 입력·배속 고지를 확인했습니다. 이 검사는 사람이 모든 프레임을 확인했다는 의미가 아닙니다.

공개 전 두 파일을 처음부터 끝까지 재생해 개인정보·알림·짧은 화면 깨짐을 최종 확인합니다. 새 사용자 설치와 다른 플랫폼의 실제 연결 검증은 [베타 확인 항목](../beta.md)에 남깁니다. 촬영 원본·자동화 스크립트·개인 데이터는 `.local/`에 보관하고 Git에 포함하지 않습니다.

설치 패키지에는 MP4를 넣지 않습니다. 패키지의 문서에서도 위 GitHub 링크로 영상을 확인할 수 있습니다. 자세한 재촬영 방법은 [촬영 기록](../demo.md)을 참고하세요.
