# CheckYourProcess — Beta

Claude Code·Codex·Claude Desktop·ChatGPT에서 작업 진행률과 현재 활동 상태를 확인하는 로컬 확장입니다.

[English](../README.md) · [앱별 설치 안내](installation.md) · [구조](architecture.md)

현재 버전은 **0.1.0-beta.5**입니다. [베타 사용 안내](beta.md)에 따라 작은 로컬 작업부터 시험해 보세요.

흑백 8비트 패널에 핵심 정보를 한 줄로 표시하고, 상세 보기를 펼쳐 작업 목록과 연결된 세션을 확인합니다. 한글·영문 Galmuri11 픽셀 폰트를 포함해 외부 폰트 연결 없이 표시합니다. **세션별 / 프로젝트 통합 보기**와 **한국어 / English**를 선택할 수 있습니다. 언어 설정은 모든 확장에서 공유되며 사용자가 작성한 프로젝트명·작업명은 번역하지 않습니다.

```text
프로젝트명 · 실행 중 · ██████░░░░ 60% · 3/5 완료
```

## 시작하기

Windows와 Node.js **22.20.0 이상**이 필요합니다. Node 22에서는 내장 SQLite 모듈의 실험 기능 안내가 stderr에 표시될 수 있습니다.

```powershell
npm ci
npm run typecheck
npm test
npm run build
npm start
node dist/cli.js preview
```

`preview`가 출력하는 로컬 인증 URL을 브라우저에서 열면 실제 저장 상태를 사용하는 화면을 확인할 수 있습니다. 인증 URL은 공유하지 마세요.

```powershell
npm run package
```

`release/`에 Claude Code·Codex 플러그인 ZIP과 Claude Desktop용 `.mcpb`가 생성됩니다. 런타임과 문서·라이선스를 포함하며, 인증 키·사용자 데이터베이스는 포함하지 않습니다. 앱별 상세 설치 절차는 [설치 안내](installation.md)를 참고하세요.

| 대상 | 표시 위치 |
| --- | --- |
| Claude Code | 입력창 위 공식 `AbovePrompt` 바 (대화 안 카드 없음) |
| Codex | 대화 카드 / 앱 내부 사이드 패널 |
| Claude Desktop 일반 채팅 | 직접 설치한 `.mcpb`의 대화 카드 |
| ChatGPT | 개인 MCP 연결의 대화 카드, 필요 시 공식 사설 터널 |

## 병렬 프로젝트 추적

확장을 설치했다고 모든 대화를 기록하지 않습니다. 원하는 작업에서 명시적으로 추적을 시작하세요.

> 이 작업의 진행률 추적을 시작하고, ‘웹사이트’ 프로젝트를 만들어 주세요. 구현, 테스트, 검토를 작업으로 등록해 주세요.

다른 세션에서는 같은 프로젝트를 선택하고 기존 작업 ID에 연결합니다.

> 기존 ‘웹사이트’ 프로젝트에 참여하겠습니다. 공통 작업 목록을 보여 주고, 이 세션이 맡을 작업을 선택하게 해 주세요.

서로 다른 앱과 세션이 동일한 작업 ID를 공유하면 프로젝트 집계에 한 번만 포함됩니다. 같은 이름의 작업이라고 자동으로 합치지 않습니다. 세션별 보기는 그 세션에 연결된 작업을, 프로젝트 보기는 전체 고유 작업을 계산합니다.

완료율은 `완료 작업 수 / 등록 작업 수`이며 가중치는 동일합니다. 계획이 없으면 ‘계획 없음’을 표시합니다. 새 작업을 추가하면 완료율이 내려갈 수 있습니다. 응답이 끝나거나 추적을 종료해도 남은 작업을 자동 완료하지 않습니다.

## 설정과 데이터

카드의 설정에서 표시 언어를 바꿉니다. Claude Code 바에서도 상세 보기에서 한국어·English와 세션·프로젝트 범위를 선택할 수 있습니다. Claude Code는 대화 안 카드 없이 바의 상세 보기에서 모든 작업 목록(페이지 이동), 기존 프로젝트 연결, 미연결 작업 연결까지 처리합니다. Codex·Claude Desktop 일반 채팅·ChatGPT는 MCP 카드에서 진행합니다.

상태는 기본적으로 `%USERPROFILE%/.checkyourprocess`에 저장합니다. AppData 밖의 공통 경로를 사용해 패키지 앱과 터미널의 저장소가 갈라지는 문제를 방지합니다. 모든 앱이 같은 저장 위치를 사용해야 프로젝트를 공유합니다. 필요하면 `CYP_DATA_DIR`, `CYP_PORT` 환경변수를 사용하세요. 기본 포트는 `49173`입니다. 기존 beta.1 기록은 자동 이전하지 않으므로 [beta.2 업그레이드 안내](upgrade-beta2.md)를 확인하세요.

카드는 보이는 동안 1초 간격으로 갱신하며, 조회 자체는 에이전트 활동으로 계산하지 않습니다. 연결이 끊기면 마지막 값을 유지하고 연결 상태를 표시합니다. 일반 채팅 앱은 마지막으로 보고된 상태를 보여 주며 내부 사고 상태를 추측하지 않습니다. 기존 대화 로그는 가져오지 않습니다.

ChatGPT 연결에 터널을 사용하면 데이터베이스는 PC에 유지되지만 조회한 작업 정보는 연결된 호스트를 거칩니다. 해당 계정의 커스텀 MCP·터널 권한과 실행 중인 터널 클라이언트가 필요합니다.

서비스 종료: `node dist/cli.js stop`. 확장을 삭제해도 데이터베이스는 자동 삭제되지 않습니다.

## 공개 배포와 확인 범위

소스는 MIT 라이선스로 공개할 수 있고, 생성한 패키지는 GitHub Releases에 첨부할 수 있습니다. GitHub 공개와 각 회사 플러그인 디렉터리 등록은 별도입니다. 이 버전의 로컬 훅은 수동 데스크톱 설치를 대상으로 합니다.

앱별 확장은 구현되어 있으나 실제 계정의 설치·UI 표시·터널 연결은 해당 호스트에서 별도 확인해야 합니다. 인증 파일, SQLite 데이터베이스, `.env`, `.local/`은 공개 저장소나 배포물에 넣지 마세요.

Anthropic·OpenAI·Ponytail과 제휴한 프로젝트가 아닙니다. ponytail의 UI 방식을 참고해 독립적으로 구현했습니다.
